=== LESSON
id: error-handling
level: Advanced
title: Error handling
--- text
`try` runs code that might fail. If it fails, `catch` runs instead of the program crashing. `throw new Error("...")` reports a problem on purpose.
--- example
try {
  const data = JSON.parse("not json");
  console.log(data);
} catch (error) {
  console.log("Could not read the data");
  console.log(error.message);
}
console.log("The program keeps running");
--- task
Write `safeDivide(a, b)`. When b is 0 it must throw an Error with the message `Cannot divide by zero`. Otherwise it returns a / b.

--- hint
Check b with an if at the top of the function and throw there.
--- solution
function safeDivide(a, b) {
  if (b === 0) {
    throw new Error("Cannot divide by zero");
  }
  return a / b;
}
console.log(safeDivide(10, 2));
